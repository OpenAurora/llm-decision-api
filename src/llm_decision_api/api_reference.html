问题类型

每个问题包含 type 和 instructions，并按题型定义 criteria。同一次请求可混合三种题型，各题独立判断。

instructionsstring | object | array必填

本题要判断的内容，不可为空。需要附带参考数据时，可使用对象或数组。

Noul条件判断

判断一个条件是否成立，返回 0～1 的成立概率。

criteria object | null · 可选
可用 "true"、"false" 自定义正反描述，值为字符串、对象或数组；未提供的项使用默认描述。

criteria object · 必填
2～{{max_options}} 项，键为选项名称，值为字符串、对象、数组或 null。值为 null 时使用名称作为描述。

Score等级评分

按有序等级评估资料，返回各等级下标的概率加权平均。

criteria array · 必填
2～{{max_options}} 项，按等级顺序排列，下标从 0 开始。每项为字符串、对象或数组。
Score 问题定义 · 放入 questions

问题 ID 与选项名称不可为空白，请求不接受未定义字段。

answersmap<string, Answer>

键与请求中的问题 ID 一一对应，值为下文的 Answer。

usageobject

input_tokens 和 output_tokens 分别为本次请求的输入、输出 token 合计。

答案类型

每个答案的 type 与对应问题一致。

Noul 答案

noul 是 0～1 的数值，越接近 1，表示条件越可能成立；不返回额外的 confidence。

answers 中的单个答案
{{noul_answer}}

Choice 答案

字段说明
choice所选选项名称，与 criteria 的键对应。
probabilities每个选项的概率，总和为 1。
confidence按选项数量缩放的最高概率优势，范围 0～1。
answers 中的单个答案
{{choice_answer}}

Score 答案

字段说明
score等级下标的概率加权平均，范围 0～等级数减 1，可以是小数。
legend等级下标到原始描述的映射，保留对象与数组结构。
probabilities每个等级的概率，总和为 1；键为字符串下标。
confidence等级概率的集中程度，范围 0～1。
answers 中的单个答案
{{score_answer}}

概率与 confidence 反映候选之间的评分分布，不等同于实际判断正确率。

错误处理

任一问题失败，整个请求返回错误，不返回部分答案。可用响应头 X-Request-ID 对照服务日志。

错误响应示例
{
  "error": {
    "code": "invalid_request",
    "message": "请求字段校验失败。",
    "request_id": "..."
  }
}

错误可能附带问题 ID question_id 或字段校验信息 details。

状态码说明
400 / 422JSON 无效或参数校验失败，按错误信息修正请求。
401服务访问密钥缺失或无效。
404 / 405接口路径或 HTTP 方法不正确。
408 / 413 / 415请求体接收超时、体积过大或媒体类型不支持。
499客户端已断开连接，记录于服务日志。
500 / 502服务内部错误，或上游模型连接、响应异常。
503 / 504服务暂不可用，或模型调用、决策处理超时。
